# Scout

Public-safe replacement for Interview Conversation Map. `src/data/interview-map-seed.json` is the Sep 4, 2026 source snapshot; `src/data/model.ts` normalizes opportunities, people, milestones, next actions, evidence, unknown company footprints, and priority.

Run `npm install`, `npm run validate:data`, then `npm run dev`. Build with `npm run build`. Validate a Vercel Preview before promoting to `scout.psstmatt.com`. Geography remains explicitly unknown until public provenance is added.
